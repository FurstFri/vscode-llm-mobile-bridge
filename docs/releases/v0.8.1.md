# v0.8.1

## The panel now says why a machine is invisible to the phone

Two setups fail silently, and both look identical from the phone — the
machine simply never appears:

- **The relay is not configured on this machine.** Settings do not cross the
  Remote-SSH boundary: a `relayUrl` set on the PC is not inherited by a
  remote host, so its gateway runs but never dials the relay. The panel now
  shows the relay URL when it is set, and a warning ("Ретранслятор не
  настроен — телефон не увидит эту машину") when it is not; clicking opens
  the setting.
- **The extension is missing on the remote host.** VS Code then quietly runs
  it on the local machine instead, so a remote window serves the PC's
  sessions and its "Copy Pairing Payload" hands out the PC's token. The
  panel now flags this with a warning row that opens the Extensions view.

Both rows carry the machine name, so it is obvious which machine a panel
belongs to when several windows are open.
