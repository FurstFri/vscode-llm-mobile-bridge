# v0.10.1

## Fix: AskUserQuestion now shows a card on the phone

The v0.10.0 hook that turned the agent's questions into a phone card was
wired to `canUseTool`, but Claude Code's `AskUserQuestion` tool bypasses
permission checks entirely — it drives its own UI. In a headless session
that UI never rendered, so the tool sat in the transcript with a spinner
forever, waiting for an answer that had no way to arrive.

Interception moved to a `PreToolUse` hook with a matcher on
`AskUserQuestion`. The hook fires before the SDK tries to run the tool,
publishes the question and its options to the phone, waits for the pick and
returns a `permissionDecision: "deny"` with the chosen answer as the reason
— the SDK forwards that string to the model as the tool's outcome, so the
turn continues with the user's answer.
