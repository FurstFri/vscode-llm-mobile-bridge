# v0.10.0

## The panel's interactivity, on the phone

Two more things that only existed inside VS Code now work from the phone.

### Modes

The composer gains a mode chip mirroring the panel's Modes picker, applied
to the turn you send:

| Chip | SDK mode | Behaviour |
|---|---|---|
| авто | `auto` | approves what passes a safety check, pauses on anything risky |
| спрашивать | `default` | asks before each edit (the prompt arrives on the phone) |
| править сразу | `acceptEdits` | edits files without asking |
| план | `plan` | explores and proposes a plan before editing |
| без ограничений | `bypassPermissions` | allows everything, including commands |

Leaving it unset keeps whatever the machine is configured with.

### The agent's questions

When the agent asks the user to choose, the question and its options now
appear as a card in the chat; tapping an option answers it. The tool has no
interface in a headless session, so the choice is handed back as the tool's
outcome — the agent continues with the answer instead of stalling.

Effort levels and per-turn model selection shipped earlier, so a phone turn
now carries model, effort and mode, and can answer both permission prompts
and questions.
