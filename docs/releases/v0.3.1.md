# v0.3.1

## Android UI overhaul — VS Code panel look

- Dark Modern palette and layout modeled on the Claude Code / Codex VS Code
  panels: flat session list with provider dots (Claude coral, Codex teal),
  hairline dividers, slim headers with connection status.
- Chat view: user prompts as bordered blocks, assistant replies as plain
  flowing text with the ⏺ bullet, collapsible reasoning (✳) and tool calls
  with status dots and monospace output.
- VS Code-style composer: bordered input with accent send button.
- Chat opens at the newest message (instant jump on first load, smooth
  scroll for streamed updates).
- Message timestamps (HH:mm, or dd.MM HH:mm for older days) on user and
  assistant messages; the chat header shows the last-activity time.
- Timestamps flow end to end: `TimelineItem.at` is populated from Claude
  transcript timestamps and Codex item timestamps, and live-streamed turn
  events are stamped at receive time.

## Artifacts

- `artifacts/llm-mobile-bridge.vsix` — VS Code extension (protocol carries `at`)
- `artifacts/llm-mobile-bridge-debug.apk` — Android client with the new UI
