# v0.1.0 — local MVP

The first private release contains a runnable local VS Code-to-Android bridge
for viewing existing Claude Code and Codex conversations.

## Included

- VS Code extension lifecycle and trusted-workspace checks;
- authenticated loopback WebSocket gateway;
- opaque public session references and single-writer registry;
- read-only Claude Agent SDK and Codex App Server adapters;
- Android Kotlin/Jetpack Compose client;
- Android Keystore encrypted pairing storage and `FLAG_SECURE`;
- session list and normalized transcript timeline.

## Install

Install `llm-mobile-bridge.vsix` in VS Code and
`llm-mobile-bridge-debug.apk` on the Android device. Run
`LLM Mobile Bridge: Copy Pairing Payload` in a trusted workspace and paste the
JSON payload into the Android app.

For an Android emulator the default URL is `ws://10.0.2.2:8765`. For a physical
USB device, use `adb reverse tcp:8765 tcp:8765` and set the extension's mobile
URL to `ws://127.0.0.1:8765`.

## Known limitations

- Existing provider sessions are intentionally read-only.
- The MVP transport is loopback-only and intended for emulator or USB/ADB use.
- The public WSS/E2EE relay, passkeys, remote revocation service, and release APK
  signing are not included yet.
