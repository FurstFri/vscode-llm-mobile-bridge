# v0.3.2

## Live transcript updates on the phone

- The open chat now polls its snapshot every 5 seconds, so turns driven from
  the VS Code panels (Claude Code / Codex) appear on the phone as they land
  in the session — previously the transcript loaded once and went stale.
- The session list refreshes every 15 seconds while open.
- Background polls no longer wipe an in-flight message: while a phone turn
  is running, snapshots are skipped until the turn ends.
- Auto-scroll follows new messages only when the reader is already near the
  bottom; scrolling up to read history is no longer interrupted.

## Artifacts

- `artifacts/llm-mobile-bridge.vsix` — VS Code extension (unchanged behavior)
- `artifacts/llm-mobile-bridge-debug.apk` — Android client with live updates
