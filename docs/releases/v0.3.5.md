# v0.3.5

## Android: panel-style tabs, auto-reconnect, screenshots allowed

- **Swipeable provider tabs.** The session list is split into CLAUDE CODE
  and CODEX pages (VS Code panel-style tab strip with provider-colored
  indicator); switch by swipe or tap.
- **Auto-reconnect.** The socket usually dies while the phone is locked;
  the app now reconnects immediately on screen wake / return to foreground
  and retries every 5 seconds while paired but disconnected.
- **Screenshots and screen recording are allowed**: `FLAG_SECURE` removed
  by user request (and intentionally not coming back).
- **Composer restyled after the Claude Code panel**: accent-bordered box
  with the `+` / `/` bottom row and a square send button. `/` prefixes the
  message for slash-style commands; `+` (attachments) is reserved for a
  future release.

Toward full panel parity, still on the roadmap: starting new chats from
the phone, tool-approval prompts, model/effort switching, attachments.
