# v0.2.0

## Highlights

- **Sessions from all projects.** The gateway now lists Claude Code and Codex
  sessions across every local project by default (previously only the current
  workspace folder). New settings: `llmMobileBridge.sessionScope`
  (`all`/`workspace`) and `llmMobileBridge.sessionLimit`. Session lists carry
  the project folder name and last-activity time.
- **Sending messages works end to end.** The Android composer sends
  `turn.start`; the gateway claims a single-writer lease; the Claude adapter
  resumes the session via the Agent SDK (`query({ resume })`); the Codex
  adapter drives `thread/resume` + `turn/start` over the app-server protocol.
  Normalized events stream back to the phone, closing with `turn.end`.
  Controlled by `llmMobileBridge.allowSendingMessages` (extension, default on)
  and `BRIDGE_ALLOW_TURNS` (Docker daemon, default off — provider data is
  mounted read-only there). `llmMobileBridge.claudePermissionMode` selects the
  permission mode for phone-initiated Claude turns.
- **Extension side panel.** New "LLM Bridge" Activity Bar view with gateway
  status, start/stop/copy-pairing/disconnect actions, per-provider session
  lists, and read-only transcript tabs.
- **Android client.** Message composer with optimistic echo and streamed
  updates, session metadata (project, recency) on cards, snapshot refresh when
  a turn completes.
