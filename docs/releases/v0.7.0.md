# v0.7.0

## Renamed publisher and Android package

The VS Code publisher is now `furstfri` and the Android application id is
`com.furstfri.llmmobilebridge`. The previous internal name is gone from the
sources, the build outputs and the repository history; release assets built
before this version were removed, since the old identifiers were compiled
into them.

## What this means when updating

Both identifiers are how the platforms tell applications apart, so this
release installs **alongside** the previous build rather than over it.

1. **VS Code** — list what is installed and remove anything that is not the
   new id, then install the new VSIX:

   ```powershell
   code --list-extensions | Select-String "llm-mobile-bridge"
   code --uninstall-extension <старый-идентификатор-из-списка>
   code --install-extension llm-mobile-bridge.vsix --force
   ```

   Settings survive (they are keyed by `llmMobileBridge.*`, not by the
   publisher). The pairing token and the session-reference secret live in
   `SecretStorage` under the extension id, so a **new token is generated** —
   copy the pairing payload to the phone again.

2. **Android** — uninstall the old app first; the new one is a separate
   package and cannot upgrade it in place. Paired machines have to be added
   again.
